# Pokémon Psyduck Yellow — opening playtest

This standalone page contains a modification patch, never a Nintendo ROM. Open it in a current browser, select the original unmodified USA HeartGold `.nds`, choose **Create my playable NDS**, and download the verified local result. Start a new game in your DS emulator. The original stays on your device.

Intended hosted address: https://thatanarchydude.github.io/corvus-workshop/psyduck-yellow/

If GitHub Pages has not been enabled, a public HTML preview service can serve this standalone file directly from its GitHub commit; no build service or ROM upload is needed. The local builder was tested in Chromium. Availability of external hosting is separate from that test.

Current scope: Pallet opening and the bounded first Route 1 grass path. Oak's capture uses field animation; a complete capture battle and new title-screen artwork are deferred. Pokémon Center menus retain normal HeartGold behavior; shared item-storage access is deferred until those Center maps are implemented.
